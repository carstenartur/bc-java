# ML-DSA Montgomery row products

The expanded matrix has coefficients in [0,q−1], q=8,380,417. The key generation, public-key derivation, signing and verification paths start the eight-level forward NTT with coefficient absolute values ≤2¹⁹, including the fixed-width decoding ranges for malformed inputs. From an absolute input bound B, a butterfly yields at most B+ceil(4,108,315·B/2³²+q/2). The eighth bound is 34,162,429. A row of at most seven terms therefore has absolute sum ≤2,004,067,566,133,248, below q·2³¹. One Montgomery reduction of the long sum produces the same residue as the old sum of reduced terms. Independently owned matrix-product outputs are normalized on the existing inverse-NTT path before encoding. Verification subtracts c·2ᴰt1 before its reduction.

The fork's native MLDSATest and new package tests passed all 15 methods on ab16374d, exercising all public parameter sets, encoded results, out-of-range eta encodings, coefficient boundaries and input preservation. In the paired fork measurements, signing/verification took 1.2–5.9% less median CPU time while keygen took 0.3–2.8% more. Allocation stayed unchanged to measurement precision. The shared host's control runs varied by several percent.
